# PZCode

  PZCode is a small, beginner-friendly programming language and interpreter written in Python.

  PZCode uses `.pzc` files as its source files. The interpreter reads these files and executes the commands inside them.

  ## Features

  PZCode currently supports:

  - Printing text and values
  - Variables
  - Basic mathematics
  - User input
  - Conditions
  - `else` statements
  - Counted loops
  - `repeat while` loops
  - Random numbers
  - Text conversion
  - Text length checking
  - Waiting
  - Clearing the screen
  - Running `.pzc` files
  - Interactive help commands

  ## Example

  ```pzc
  store 10 in score
  store score + 25 in final_score
  say final_score

  ## Project Status

  PZCode is an open-source learning project and is still being developed.

  The project is intended to help beginners understand:

  - How interpreters work
  - How programming languages process commands
  - How variables and expressions are handled
  - How source files can be executed
